FC Maps is an interactive atlas of professional football and a product of TdB GEO. This edition follows the Eredivisie 2026/27, plotting where every player in every club squad was born.

{% endblock %} {% block about_project %}

Open project. The Eredivisie atlas is the second map in this project, after the World Cup 2026 edition. Squad data is added once the season is under way, so the map fills in as rosters are confirmed. The code is open source — all feedback, corrections, and collaborations are welcome.
